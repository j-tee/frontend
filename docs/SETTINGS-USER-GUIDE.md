# 🎨 Settings - User Guide

## Quick Start

### Change Your Currency

1. Click **Settings** in the sidebar
2. You'll see **Currency & Regional** tab (already selected)
3. Click the **Currency** dropdown
4. Select your currency (e.g., "GHS - Ghanaian Cedi (₵)")
5. See the preview update instantly
6. Click **Save Changes** button (top right)
7. ✅ All prices now show in your currency!

**Example:**
- Before: `$1,234.56`
- After (GHS): `₵1,234.56`
- After (NGN): `₦1,234.56`

---

### Change Your Theme

1. Click **Settings** in the sidebar
2. Click **Appearance** tab
3. Click on any color theme box
4. Watch your app colors change instantly!
5. Click **Save Changes**

**Available Themes:**
- 🔵 **Default Blue** - Professional and trustworthy
- 🟢 **Emerald Green** - Fresh and modern
- 🟣 **Purple Galaxy** - Creative and bold
- 🟠 **Sunset Orange** - Warm and energetic
- 🩵 **Ocean Teal** - Calm and peaceful
- 🌸 **Rose Pink** - Friendly and approachable
- ⚫ **Slate Minimal** - Clean and sophisticated

---

### Change Light/Dark Mode

1. Go to **Settings** → **Appearance**
2. Click one of three buttons:
   - ☀️ **Light** - Bright white backgrounds
   - 🌙 **Dark** - Dark backgrounds (easier on eyes)
   - 🌗 **Auto** - Matches your computer's setting

---

### Make Text Bigger/Smaller

1. Go to **Settings** → **Appearance**
2. Under **Font Size**, click:
   - **Small** - Compact text
   - **Medium** - Default size
   - **Large** - Easier to read

---

### Compact Mode (For Power Users)

Want to see more on screen? Enable **Compact Mode**:

1. Go to **Settings** → **Appearance**
2. Toggle **"Compact mode (reduce spacing)"** ON
3. Everything gets a bit smaller and tighter
4. See more data without scrolling!

---

### High Contrast (For Better Visibility)

If you have trouble seeing colors:

1. Go to **Settings** → **Appearance**
2. Toggle **"High contrast mode"** ON
3. Borders become darker
4. Text becomes bolder
5. Easier to distinguish elements

## Tips & Tricks

### 💡 Best Practices:

1. **Choose Your Currency First** - Do this before entering any prices

### ⚡ Quick Tips:

## Troubleshooting

### "Save Changes" button shows error

**Problem:** Settings not saving

**Solution:**
1. Check your internet connection
2. Make sure you're logged in
3. Try again in a few seconds
4. If still failing, contact support

### Theme colors look weird

**Possible causes:**
1. Try a different theme
2. Disable browser extensions (they might interfere)
3. Clear browser cache
4. Try a different browser

### Dark mode not working

**Check:**
1. Did you select "Dark" or "Auto"?
2. If "Auto" - check your computer's system settings
3. Try selecting "Dark" explicitly
4. Save changes after selecting

## FAQs

**Q: Will my settings affect other users?**  
A: No! Each user has their own personal settings.

**Q: Do I need to save settings every time?**  
A: Yes, click "Save Changes" to make them permanent.

**Q: Can I change currency after entering sales?**  
A: Yes, but existing sales will still show in old currency. Only new sales use the new currency.

**Q: Which theme is most professional?**  
A: Default Blue or Slate Minimal are great for corporate/professional settings.

**Q: Can I create my own theme?**  
A: Not yet, but it's coming in a future update!

**Q: Does dark mode save battery?**  
A: Yes, especially on OLED screens!

**Q: What happens if I don't save changes?**  
A: Your changes will be lost when you leave the page.
